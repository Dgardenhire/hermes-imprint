Where the bundled font files came from, and their Montserrat and Lora (added 2026-11-09, for the Harborlight sample brand, whose guide names them) come from the
Google Fonts repository (github.com/google/fonts, ofl/montserrat and ofl/lora), downloaded on Damon's approval and
handed to this build as local files with each family's OFL.txt (kept as OFL-montserrat.txt and OFL-lora.txt).
Lora carries the Reserved Font Name "Lora", so its variable files are shipped unmodified (renamed only); the PDF
embedder and Pillow use their default instance, weight 400. Montserrat has no Reserved Font Name; its variable file
(default weight 100) was cut to static instances with fontTools 4.60.2 (varLib.instancer, wght 400, 600, 700, 800).

    montserrat-400.ttf ... montserrat-800.ttf   Montserrat[wght].ttf, static instances
    lora-400.ttf                                 Lora[wght].ttf, unmodified
    lora-400-italic.ttf                          Lora-Italic[wght].ttf, unmodified
